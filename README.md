# NovaStream IPTV Pro (Android & Android TV)

Bu proje, GitHub Actions uzerinden otomatik olarak derlenip icinde `classes.dex`, `lib/`, `res/`, `kotlin/`, `META-INF/` ve `AndroidManifest.xml` barindiran tam tesekkullu **Release APK** uretmek uzere hazirlanmistir.

## GitHub'a Yukleme ve APK Alma Adimlari
1. Bu ZIP dosyasinin icindeki klasor ve dosyalari oldugu gibi GitHub deponuza yukleyin.
2. **Actions** sekmesine gecin.
3. **Build NovaStream IPTV Pro APK** akisi otomatik calisacak ve size indirilebilir `.apk` dosyasini verecektir.
